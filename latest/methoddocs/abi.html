ABI

class ethpm_types.abi.ABIType(*, name: str | None = None, type: str | ABIType, components: list[ABIType] | None = None, internalType: str | None = None, **extra_data: Any)
property canonical_type: str

The low-level type recognized by the virtual machine. For example, a tuple is converted to comma-separated string of its components.

components: list[ABIType] | None

A field of sub-types that makes up this type. Tuples and structs tend to have this field.

internal_type: str | None

Another name for the type. Sometimes, compilers are able to populate this field with the struct or enum name.

name: str | None

The name attached to the type, such as the input name of a function.

property signature: str

If the type has name, returns "<canonical_type> <name>". Else, returns "<canonical_type>".

type: str | ABIType

The value-type, such as address or address[].

An ABI describing a contract constructor. NOTE: The constructor ABI does not have a name property.

inputs: list[ABIType]

Contract constructor arguments.

property is_payable: bool

Returns True if the contract accepts currency upon deployment.

property selector: str

String representing the constructor selector.

property signature: str

String representing the function signature, which includes the arg names and types, for display purposes only.

stateMutability: str

Can be either "payable" or "nonpayable". Defaults to the value "nonpayable".

type: Literal['constructor']

The value "constructor".

encode_topics(inputs: dict[str, Any]) → list[str | list[str] | None]

Encode the given input data into a topics list, useful for log-filtering. Missing topics correspond to None values in the returns list, which work as wildcards in eth_getLogs.

Parameters:

inputs (dict[str, Any]) – Input data that will be encoded.

Returns:

Encoded topics.

Return type:

list[Optional[str]]

An ABI representing a method you can invoke from a contact.

classmethod from_signature(sig: str) → MethodABI

Create an MethodABI instance from a method signature.

NOTE: Method return types and state mutability are not included in signatures.

Therefore, they will not necessarily be accurate in the resulting MethodABI instance.

inputs: list[ABIType]

Inputs to the method as ABIType objects.

property is_payable: bool

Whether the method expects currency or not.

property is_stateful: bool

Whether the method alters the state of the blockchain (and likely requires a transaction).

name: str

The name of the method.

outputs: list[ABIType]

What the method returns as ABIType objects.

property selector: str

String representing the function selector, used to compute method_id.

property signature: str

String representing the function signature, which includes the arg names and types, and output names and type(s) (if any) for display purposes only.

stateMutability: str

Can be either "payable" or "nonpayable". Defaults to the value "nonpayable".

type: Literal['function']

The value "function".

class ethpm_types.abi.UnprocessedABI(*, type: str)

An ABI representing an unknown entity. This is useful for supporting custom compiler types, such as types defined in L2 ecosystems but are not in Ethereum.
